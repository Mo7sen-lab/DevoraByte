# DevoraByte website

Responsive one-page portfolio and web-development studio website built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser or use Live Server in VS Code. Keep `index.html`, `style.css`, and `script.js` in the same folder.

## Animations included
- Smooth hero entrance and subtle floating interface cards
- Scroll-reveal animations for sections and cards
- Hover motion for project previews and buttons
- Reduced-motion support for visitors who prefer fewer animations

Before publishing, verify contact email and social links in `script.js`.
